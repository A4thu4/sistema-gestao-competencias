# UC-06 — Gerenciar plano de desenvolvimento

> Dica: caso de uso completo (*fully dressed*, Larman cap. 6) pedido na Parte III, a partir do caso resumido do Marco 4 (abaixo). Siga o [modelo](modelo-caso-de-uso.md) e os UC-01 a UC-05 como exemplo. Apague esta dica e o resumo quando terminar.
>
> Resumo do Marco 4: Depois que o resultado do ciclo é liberado, o gestor abre o plano de desenvolvimento do colaborador e, junto com ele, registra as metas, cada uma ligada a uma competência (por exemplo, as de menor média no ciclo), com as ações previstas (como um curso), o prazo e a situação. O sistema salva o plano no histórico do colaborador. A cada trimestre, o sistema envia por e-mail um lembrete ao gestor e ao colaborador para revisarem as metas; o colaborador registra o progresso das ações, os dois atualizam a situação de cada meta e o sistema guarda a data de cada atualização.
