# Questionários

Modelo do questionário, respostas dos 2 respondentes e síntese dos requisitos. Os respondentes são pessoas diferentes das entrevistadas. Cada questionário respondido é uma fonte `QUE-N` na matriz de rastreabilidade.

| ID    | Arquivo         | Descrição                                        | Status   |
|-------|-----------------|--------------------------------------------------|----------|
|       | questionario.md | Modelo do questionário (perguntas)               | Concluído|
| QUE-1 | resposta-1.md   | Questionário preenchido: [função do respondente] | Pendente |
| QUE-2 | resposta-2.md   | Questionário preenchido: [função do respondente] | Pendente |
|       | sintese.md      | Síntese dos requisitos dos questionários         | Pendente |

Cada resposta traz a identificação do respondente (nome, função e telefone). O termo de consentimento fica em [anexos](../anexos).
