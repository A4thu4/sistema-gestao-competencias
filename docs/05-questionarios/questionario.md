# Questionário de levantamento de requisitos

Questionário para levantamento de requisitos do **Sistema de Gestão de Competências**. Complementa as entrevistas: em vez de conversa aberta, usa perguntas fechadas, que permitem medir a importância de cada funcionalidade e comparar respondentes.

## Aplicação

| Item | Definição |
| --- | --- |
| Respondentes | 2 pessoas **diferentes** das entrevistadas (QUE-1 e QUE-2). De preferência, uma que avalia e uma que é avaliada. |
| Tempo estimado | 10 a 15 minutos |
| Meio | Google Forms (com a seção 0 como primeira página e a concordância obrigatória) ou impresso |
| Registro | Copiar este arquivo como `resposta-1.md` e `resposta-2.md` e marcar as respostas: `(x)` para escolha única e `[x]` para múltipla escolha. Se aplicado no Forms, anexar também o PDF das respostas. |
| Consentimento | Termo assinado antes da aplicação (em `docs/anexos`) |
